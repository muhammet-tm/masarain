# Font licenses

The files in `fonts/` are subsets of three typefaces published on Google Fonts. Each typeface is licensed under the SIL Open Font License, Version 1.1, which permits use, embedding, and redistribution, provided that each copy carries the copyright notice and the license. Each font file carries its copyright notice and the address of the license in its own metadata; the notices are repeated in the table below.

| File | Typeface | Copyright notice recorded in the file |
|---|---|---|
| `big-shoulders-display-latin.woff2` | Big Shoulders Display | Copyright 2019 The Big Shoulders Project Authors (https://github.com/xotypeco/big_shoulders) |
| `archivo-latin.woff2` | Archivo | Copyright 2020 The Archivo Project Authors (https://github.com/Omnibus-Type/Archivo) |
| `martian-mono-latin.woff2` | Martian Mono | Copyright 2020 The Martian Mono Project Authors (https://github.com/evilmartians/mono) |

The full text of the SIL Open Font License 1.1 is at https://openfontlicense.org.
